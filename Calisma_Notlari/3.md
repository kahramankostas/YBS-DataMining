## 2. NumPy: Dizi (ndarray) Mantığı

### 2.1 Neden liste değil de dizi?

| Python listesi | NumPy dizisi |
|---|---|
| Farklı tipleri bir arada tutabilir | **Tek tip** veri tutar |
| İşlemler döngüyle, tek tek yapılır | İşlemler C dilinde, **toplu** yapılır (defterde ~50–100 kat hızlı) |
| `[1, 2, 3] * 2` → `[1, 2, 3, 1, 2, 3]` (**tekrar**) | `np.array([1, 2, 3]) * 2` → `[2 4 6]` (**çarpma**) |

> ⚠️ Aynı `*` işareti listede "tekrarla", dizide "çarp" demektir. Bu fark, başlangıçta en sık karşılaşılan hatalardan biridir.

### 2.2 Dizinin kimlik kartı

| Özellik | Anlamı | `satislar = np.array([120, 135, 98, 150, 210, 305, 280])` için |
|---|---|---|
| `.ndim` | Boyut sayısı | `1` |
| `.shape` | Şekil (satır, sütun…) | `(7,)` |
| `.size` | Toplam eleman sayısı | `7` |
| `.dtype` | Veri tipi | `int64` |

2 boyutlu bir dizide `shape` her zaman **(satır, sütun)** sırasıyla okunur. 3 şube × 4 çeyreklik bir ciro tablosunun şekli `(3, 4)`'tür.

### 2.3 Hazır dizi üreticiler

| Komut | Sonuç | Not |
|---|---|---|
| `np.zeros(5)` | `[0. 0. 0. 0. 0.]` | |
| `np.ones((2, 3))` | 2×3 birler matrisi | Şekil **demet (tuple)** olarak verilir |
| `np.full(4, 7)` | `[7 7 7 7]` | |
| `np.arange(0, 20, 5)` | `[0 5 10 15]` | Bitiş **dahil değil** |
| `np.linspace(0, 1, 5)` | `[0. 0.25 0.5 0.75 1.]` | Bitiş **dahil**, eleman **sayısı** verilir |
| `np.eye(3)` | 3×3 birim matris | |

> 🧠 **arange mı linspace mi?** "Adımı biliyorum" → `arange`. "Kaç tane sayı istediğimi biliyorum" → `linspace`.

### 2.4 Veri tipleri önemlidir

NumPy bir diziye farklı tipler koyarsanız hepsini **ortak bir tipe** çevirir:

| Kod | `dtype` | Ne oldu? |
|---|---|---|
| `np.array([1, 2, 3])` | `int64` | |
| `np.array([1, 2.5, 3])` | `float64` | Hepsi ondalıklı oldu |
| `np.array([1, "iki", 3])` | `<U21` (metin) | **Hepsi metin oldu!** Artık toplama yapamazsınız |
| `np.array([1.9, 2.7, -1.7]).astype(int)` | `[ 1  2 -1]` | `astype(int)` yuvarlamaz, **ondalığı keser** |

> 🔗 **2. haftayla bağlantı:** Bir sütuna tek bir yanlış girilmiş metin ("yok", "-") karışırsa bütün sütun metne döner. Bu, "tutarsız veri"nin kodda nasıl göründüğüdür.

## 3. NumPy: Seçme, Maskeleme, Vektörel İşlem

### 3.1 İndeksleme ve dilimleme

- İndeksler **0'dan** başlar; negatif indeks sondan sayar (`[-1]` = son eleman).
- Dilim: `başlangıç:bitiş:adım` → bitiş **dahil değildir**.

| Kod (`gunler = ["Pzt", "Sal", "Çar", "Per", "Cum", "Cmt", "Paz"]`) | Sonuç |
|---|---|
| `gunler[0]` / `gunler[-1]` | `Pzt` / `Paz` |
| `gunler[:5]` | Hafta içi (ilk 5) |
| `gunler[5:]` | Hafta sonu |
| `gunler[::2]` | Birer atlayarak |
| `gunler[::-1]` | Ters sıra |

2 boyutta `dizi[satır, sütun]`: `ciro[1, 2]` → 2. şube, 3. çeyrek · `ciro[:, 3]` → tüm şubeler, 4. çeyrek · `ciro[0]` → 1. şubenin tüm yılı.

> ⚠️ **Dilim bir kopya değil, görünümdür (view)!**
> ```python
> a = np.array([10, 20, 30, 40, 50])
> parca = a[1:3]
> parca[0] = 999
> print(a)        # [ 10 999  30  40  50]  ← orijinal de değişti!
> ```
> Bağımsız bir parça istiyorsanız `a[1:3].copy()` kullanın.

### 3.2 Boolean maskeleme ⭐

Veri madenciliğinde **en çok kullanılan** seçim tekniğidir: bir koşul yazarsınız, NumPy koşulu sağlayanları getirir.

```python
notlar = np.array([45, 78, 92, 33, 67, 88, 51, 29, 95, 60])
maske = notlar >= 50         # [False True True False True True True False True True]
notlar[maske]                # [78 92 67 88 51 95 60]
maske.sum()                  # 7   → True = 1, False = 0 sayılır
maske.mean()                 # 0.7 → geçme oranı %70
```

| Mantıksal işlem | İşaret | Örnek |
|---|---|---|
| VE | `&` | `notlar[(notlar >= 60) & (notlar <= 90)]` |
| VEYA | `\|` | `notlar[(notlar < 35) \| (notlar > 90)]` |
| DEĞİL | `~` | `notlar[~(notlar < 50)]` |

> ⚠️ **Parantezler zorunludur.** `notlar >= 60 & notlar <= 90` hata verir, çünkü Python `&` işlemini karşılaştırmadan **önce** yapar. Ayrıca `and` / `or` sözcükleri dizilerde çalışmaz; `&` ve `|` kullanın.

> 💡 **Hile:** `maske.sum()` "kaç tane?", `maske.mean()` "yüzde kaç?" sorusunun cevabıdır. Sınav sorularında çok işe yarar.

### 3.3 `np.where`: Excel'deki EĞER

```python
np.where(notlar >= 50, "Geçti", "Kaldı")
# Bütünlemeye girenlere +10 puan, ama 100'ü geçmesin:
np.where(notlar < 50, np.minimum(notlar + 10, 100), notlar)
# [55 78 92 43 67 88 51 39 95 60]
```

`np.where(koşul)` tek argümanla kullanılırsa koşulu sağlayan elemanların **konumlarını** verir: `np.where(notlar > 90)[0]` → `[2 8]`.

### 3.4 Vektörel işlemler ve ufunc'lar

Döngü yazmadan, eleman eleman hesap:

```python
fiyat = np.array([100, 250, 80, 400])
adet  = np.array([3, 1, 10, 2])
fiyat * adet               # [300 250 800 800]
(fiyat * adet).sum()       # 2150 → toplam ciro
fiyat * 1.20               # KDV dahil
```

Sık kullanılan evrensel fonksiyonlar (ufunc): `np.sqrt`, `np.log`, `np.exp`, `np.abs`, `np.round`, `np.minimum`, `np.maximum`.

## 4. NumPy: `axis`, Broadcasting ve Normalleştirme

### 4.1 Toplu istatistikler

| Fonksiyon | `notlar` için sonuç |
|---|---|
| `notlar.mean()` | 63,8 |
| `np.median(notlar)` | 63,5 |
| `notlar.std()` | 22,93 (**popülasyon**, n'ye böler) |
| `notlar.min()`, `notlar.max()` | 29, 95 |
| `np.percentile(notlar, [25, 50, 75])` | [46,5 63,5 85,5] → Q1, Q2 (medyan), Q3 |
| `notlar.argmax()` | 8 → en büyük değerin **konumu** (değerin kendisi değil!) |

> ⚠️ **std tuzağı:** NumPy'ın `std()` fonksiyonu varsayılan olarak **n**'ye böler (popülasyon). 2. haftadaki kitap formülü **n − 1**'e böler (örneklem). Kitapla aynı sonucu istiyorsanız `std(ddof=1)` yazın. (pandas'ın `.std()` fonksiyonu ise varsayılan olarak n − 1 kullanır!)

### 4.2 `axis` kavramı ⭐

```
                 Ç1    Ç2    Ç3    Ç4         axis=1 (satır boyunca)
Gümüşhane     [ 2.1   2.5   3.0   3.8 ]   →   11.4
Trabzon       [ 4.2   4.0   4.9   5.5 ]   →   18.6
Bayburt       [ 1.5   1.7   1.6   2.2 ]   →    7.0
                 ↓     ↓     ↓     ↓
axis=0 →        7.8   8.2   9.5  11.5     (sütun boyunca)
```

| Komut | Sonucun şekli | Anlamı |
|---|---|---|
| `ciro.sum()` | tek sayı (37,0) | Her şeyin toplamı |
| `ciro.sum(axis=0)` | `(4,)` | Her **çeyreğin** toplamı (satırlar ezildi) |
| `ciro.sum(axis=1)` | `(3,)` | Her **şubenin** toplamı (sütunlar ezildi) |

> 🧠 **Kolay hatırlama:** `axis` parametresine verdiğiniz eksen **yok olur**. `(3, 4)` şekilli dizide `axis=0` verirseniz 3 kaybolur, geriye 4 sonuç kalır.

### 4.3 Broadcasting (yayma) ⭐

Farklı şekilli diziler arasında işlem yaparken NumPy küçük diziyi otomatik "genişletir".

**Kural:** Şekiller **sağdan** karşılaştırılır; her boyut ya **eşit** olmalı ya da biri **1** olmalı.

| İşlem | Şekiller | Sonuç | Örnek |
|---|---|---|---|
| Dizi × sayı | `(3, 4)` × `()` | `(3, 4)` | Tüm cirolara %20 KDV |
| Her sütuna farklı değer | `(3, 4)` × `(4,)` | `(3, 4)` | Her çeyreğe farklı enflasyon katsayısı |
| Her satıra farklı değer | `(3, 4)` − `(3, 1)` | `(3, 4)` | Her şubenin kendi hedefiyle farkı |
| ❌ Uyumsuz | `(3, 4)` − `(3,)` | **Hata** | 4 ile 3 eşit değil, hiçbiri 1 değil |

> 💡 Son satırdaki hatayı düzeltmek için `(3,)` şeklindeki diziyi `reshape(-1, 1)` ile `(3, 1)` yapın.

### 4.4 Uygulama: 2. haftadaki normalleştirme tek satırda

2\. haftanın çalışılmış örneğini (`X = 251, 148, 166, 244, 472, 356, 379`) kodla tekrar edelim:

```python
X = np.array([251, 148, 166, 244, 472, 356, 379])

minmaks = (X - X.min()) / (X.max() - X.min())
# [0.318 0.    0.056 0.296 1.    0.642 0.713]   ← kitaptaki tabloyla aynı

z_kitap = (X - X.mean()) / X.std(ddof=1)
# [-0.312 -1.179 -1.028 -0.371  1.55   0.573  0.767]   ← kitaptaki tabloyla aynı

z_numpy = (X - X.mean()) / X.std()
# [-0.337 -1.274 -1.11  -0.4    1.674  0.619  0.828]   ← n'ye bölündüğü için farklı

ondalik = X / 10**3
# [0.251 0.148 0.166 0.244 0.472 0.356 0.379]
```

Çok sütunlu bir tabloda (ör. yaş, gelir, alışveriş sayısı) **her sütunu ayrı** normalleştirmek için `axis=0` ve broadcasting birlikte çalışır:

```python
min_d = musteriler.min(axis=0)          # her sütunun minimumu, şekil (3,)
max_d = musteriler.max(axis=0)
normal = (musteriler - min_d) / (max_d - min_d)   # (5, 3) − (3,) → (5, 3)
```

> 🔗 Gelir sütunu (22.000–90.000) ile yaş sütunu (25–58) artık aynı [0, 1] ölçeğinde. 2. haftada "k-NN'de maaş yaşı ezer" dediğimiz sorun böyle çözülür.

### 4.5 Yeniden şekillendirme ve birleştirme

| Komut | Ne yapar? |
|---|---|
| `a.reshape(4, 3)` | 12 elemanı 4 satır × 3 sütuna diz |
| `a.reshape(-1, 6)` | `-1` = "gerisini sen hesapla" → `(2, 6)` |
| `a.T` | Transpoz (satır ↔ sütun) |
| `a.ravel()` | Düzleştir (tek boyuta indir) |
| `np.vstack([a, b])` | Alt alta ekle |
| `np.hstack([a, b])` | Yan yana ekle |

> 💡 **Gelecek haftaya not:** scikit-learn modelleri girdi olarak **2 boyutlu** `X` ister. Tek bir özelliğiniz varsa `x.reshape(-1, 1)` ile onu sütun vektörüne çevirmeniz gerekir. Bu hatayla çok karşılaşacaksınız!

### 4.6 Rastgele sayılar ve tekrarlanabilirlik

```python
rng = np.random.default_rng(seed=42)       # modern ve önerilen yöntem
rng.random(3)                              # 0–1 arası düzgün
rng.integers(1, 7, size=10)                # zar (7 dahil değil!)
rng.normal(loc=170, scale=8, size=5)       # ortalama 170, std 8
rng.choice(["Kart", "Nakit"], size=6, p=[0.7, 0.3])
rng.permutation(10)                        # karıştırma → eğitim/test bölmenin temeli
```

**Tohum (seed)** sabitlenirse herkes aynı "rastgele" sayıları alır. Bilimsel çalışmalarda ve ödevlerde bu şarttır.

### 4.7 Eksik değer: `np.nan`

```python
sicaklik = np.array([12.5, 14.0, np.nan, 11.2, np.nan, 15.8])
sicaklik.mean()                 # nan   ← tek bir eksik, bütün sonucu bozar!
np.nanmean(sicaklik)            # 13.375
np.isnan(sicaklik).sum()        # 2 eksik değer
np.where(np.isnan(sicaklik), np.nanmean(sicaklik), sicaklik)   # ortalamayla doldurma
```

> ⚠️ `np.nan == np.nan` sonucu **False**'tur. Eksik değeri `== np.nan` ile arayamazsınız; mutlaka `np.isnan()` (pandas'ta `isna()`) kullanın.

## 6. pandas: İlk Keşif ve Seçim

### 6.1 Yeni bir veri setine bakarken ilk beş komut ⭐

| Komut | Cevapladığı soru (1. haftanın "Veri Setini Tanı" listesi) |
|---|---|
| `df.shape` | Kaç gözlem, kaç özellik var? |
| `df.head()` / `df.sample(5)` | Veri neye benziyor? |
| `df.info()` | Sütun tipleri ne? Hangi sütunlarda eksik var? |
| `df.describe()` | Sayısal sütunların min/max/ortalama/çeyreklikleri (mantıksız değer var mı?) |
| `df["sutun"].value_counts()` | Kategorilerin dağılımı ne? Sınıflar dengeli mi? |

Bunlara ek olarak: `df.describe(exclude="number")` (metin ve tarih sütunları), `df["il"].nunique()` (benzersiz değer sayısı), `value_counts(normalize=True)` (oranlar).

> 🔎 **Dedektif gibi düşünün:** `describe()` çıktısında `adet` sütununun minimumu **−1** çıkıyorsa bu bir **hatalı değerdir** (sipariş adedi negatif olamaz). `info()` çıktısında bir sütunun dolu değer sayısı satır sayısından azsa o sütunda **eksik veri** vardır.

### 6.2 `[]`, `loc` ve `iloc` ⭐

| Seçim | Neye göre? | Dilimde bitiş | Örnek |
|---|---|---|---|
| `df["urun"]` | Sütun adı | – | Tek sütun → **Series** |
| `df[["urun", "adet"]]` | Sütun adları | – | Çift köşeli parantez → **DataFrame** |
| `df.loc[0:3, ["urun", "il"]]` | **Etiket** | **Dahil** → 0, 1, 2, 3 (4 satır) | |
| `df.iloc[0:3, 0:4]` | **Konum** (sıra numarası) | **Dahil değil** → 0, 1, 2 (3 satır) | |

> 🧠 **Kolay hatırlama:** `iloc`'taki **i** = *integer* (tam sayı, konum). `loc` etiketle çalışır ve etiketlerde "bitiş dahil" mantığı vardır.

### 6.3 Koşullu filtreleme

NumPy'daki maskeleme kuralları aynen geçerlidir (`&`, `|`, `~`, **parantez**). Ek olarak:

| Komut | Ne yapar? | Örnek |
|---|---|---|
| `isin([...])` | Listeden biri mi? | `df[df["il"].isin(["Trabzon", "Gümüşhane"])]` |
| `query("...")` | Koşulu metin olarak yazmak (okunaklı) | `df.query("birim_fiyat > 20000 and adet >= 3")` |
| `.str.contains(...)` | Metin içinde arama | `df[df["urun"].str.contains("Kahve")]` |

> 📝 `query` içinde `and` / `or` yazılabilir; normal maskelemede yazılamaz.

## 7. pandas: Veri Temizleme (Rafineri Hattı Kodda) ⭐⭐

| 2. Hafta stratejisi | pandas karşılığı |
|---|---|

## 8. pandas: Özellik Türetme, Gruplama, Birleştirme

### 8.1 Yeni sütun türetme (Feature Engineering)

| Amaç | Kod | 2. Hafta karşılığı |
|---|---|---|
| Aritmetik | `df["tutar"] = df["birim_fiyat"] * df["adet"]` | Özellik oluşturma |
| Tarihten bilgi çıkarma | `df["tarih"].dt.month`, `.dt.day_name()`, `.dt.dayofweek >= 5`, `.dt.quarter` | Özellik oluşturma |
| Koşullu sütun | `np.where(df["tutar"] >= 1000, "Ücretsiz", "Ücretli")` | |
| Aralıklara bölme | `pd.cut(df["tutar"], bins=[0, 500, 5000, 50000, np.inf], labels=[...])` | **Kesikleştirme** |
| Eşit frekanslı gruplar | `pd.qcut(df["M"], q=3, labels=["Bronz", "Gümüş", "Altın"])` | Kesikleştirme |
| Sözlükle eşleme | `df["ay"].map({12: "Kış", 1: "Kış", ...})` | **Genelleme** |
| Fonksiyon uygulama | `df["puan"].apply(memnuniyet)` | |

> 🧠 **cut mı qcut mu?** `cut` aralık **sınırlarını** siz verirsiniz (0–500, 500–5000…); gruplardaki kişi sayısı farklı olabilir. `qcut` her gruba **eşit sayıda** gözlem düşecek şekilde sınırları kendisi bulur.

### 8.2 Sıralama

```python
df.sort_values("tutar", ascending=False).head()
df.sort_values(["kategori", "tutar"], ascending=[True, False])   # önce A-Z, sonra büyükten küçüğe
```

### 8.3 Gruplama: `groupby` ⭐⭐

**Böl → Uygula → Birleştir (split-apply-combine).** SQL'deki `GROUP BY` ile aynıdır.

```python
df.groupby("kategori")["tutar"].sum()                     # kategori bazında ciro

df.groupby("il").agg(                                     # birden çok istatistik
    siparis_sayisi=("siparis_id", "count"),
    toplam_ciro=("tutar", "sum"),
    ortalama_puan=("puan", "mean"),
)

df.groupby(["kategori", "odeme"])["tutar"].mean().unstack()   # iki boyutlu özet
```

> 🔗 **1. haftayla bağlantı:** `groupby` + `agg`, tanımlayıcı modellerden **özetleme**nin (karakterizasyon) en basit hâlidir.

### 8.4 Pivot tablo ve çapraz tablo

| Komut | Ne zaman? |
|---|---|
| `pd.pivot_table(df, values="tutar", index="kategori", columns="mevsim", aggfunc="sum", margins=True)` | Excel'deki Özet Tablo'nun aynısı; sayısal değer özetler |
| `pd.crosstab(df["kategori"], df["memnuniyet"], normalize="index")` | İki **kategorik** değişkenin frekans/oran tablosu |

> 🔗 Pivot tablo, 1. haftadaki **OLAP veri küpünün** küçük bir dilimidir (ürün × mevsim × ciro).

### 8.5 Tabloları birleştirme: `merge` ve `concat`

| Birleştirme | Sonuç |
|---|---|
| `how="inner"` | Yalnızca **iki tabloda da** eşleşen kayıtlar |
| `how="left"` | Sol tablonun **tamamı**; eşleşmeyenlerde `NaN` |
| `how="right"` | Sağ tablonun tamamı |
| `how="outer"` | Her iki tablonun tamamı |

```python
left = siparisler.merge(musteriler, on="musteri_id", how="left")
left["uyelik"].isna().sum()        # müşteri tablosunda karşılığı olmayan sipariş sayısı
pd.concat([ocak, subat], ignore_index=True)   # aynı yapıdaki tabloları alt alta ekleme
```

> ⚠️ Defterdeki müşteri tablosunda 76–80 numaralı müşteriler **yok**. `inner` ile birleştirirseniz bu müşterilerin siparişleri sessizce kaybolur. Birleştirmeden **önce ve sonra** satır sayısını kontrol etmek iyi bir alışkanlıktır.

### 8.6 Zaman serisi özetleme

```python
aylik = df.set_index("tarih").resample("ME")["tutar"].sum()   # ME = ay sonu
```

`resample`, tarihe göre yapılan bir `groupby`'dır; 2. haftadaki **bir araya getirme (aggregation)** işleminin (günlük → aylık) kodudur.

## 9. Matplotlib: Grafiğin Anatomisi

### 9.1 İki arayüz ⭐

| | pyplot (durum tabanlı) | Nesne yönelimli (**önerilen**) |
|---|---|---|
| Yazım | `plt.plot(...)`, `plt.title(...)` | `fig, ax = plt.subplots()` → `ax.plot(...)`, `ax.set_title(...)` |
| Ne zaman? | Hızlı, tek grafiklik denemeler | Birden fazla grafik, ince ayar, raporlar |

```
Figure (tüm tuval)
 └── Axes (tek bir grafik alanı)  ← birden fazla olabilir: axes[0, 1]
      ├── başlık, eksen etiketleri
      ├── çizgiler, çubuklar, noktalar
      └── açıklama (legend), notlar (annotation)
```

### 9.2 Altın kural

> 💡 Her grafiğin bir **başlığı**, **eksen etiketleri** ve (birden fazla seri varsa) **açıklaması** olmalı. Okuyucu grafiği metni okumadan anlayabilmeli.

```python
fig, ax = plt.subplots()

ax.legend()
plt.show()
```

**Biçim kısayolları:** `color`, `linestyle` (`"-"`, `"--"`, `":"`, `"-."`), `marker` (`"o"`, `"s"`, `"^"`, `"x"`), `linewidth`, `alpha` (saydamlık 0–1).

**Faydalı eklemeler:** `ax.axhline(2.0)` (yatay referans çizgisi), `ax.axvline(...)` (dikey çizgi), `ax.set_ylim(0, 4)`, `ax.annotate("Zirve", xy=..., xytext=..., arrowprops=...)`, `ax.bar_label(cubuklar)` (çubukların üstüne değer).

```python
fig, axes = plt.subplots(2, 2, figsize=(12, 8))
fig.suptitle("Satış Gösterge Paneli")
axes[0, 0].plot(...)       # sol üst
```

`plt.subplots(1, 3)` gibi tek satırlı panellerde `axes` tek boyutludur: `axes[0]`, `axes[1]`, `axes[2]`.

## 10. Hangi Soruya Hangi Grafik?

| Soru | Grafik | Komut | Veri madenciliğinde kullanımı |
|---|---|---|---|
| Zaman içinde nasıl değişti? | Çizgi | `ax.plot` | Trend, mevsimsellik |
| Kategoriler arasında karşılaştırma? | Sütun / yatay sütun | `ax.bar`, `ax.barh` | Kategori cirosu, sınıf dengesi |
| Değişken nasıl dağılmış? | Histogram | `ax.hist` | Çarpıklık, aykırı değer, ölçek seçimi |
| Gruplar arası dağılım, aykırı değer? | Kutu grafiği | `ax.boxplot` | **Gürültü / aykırı değer tespiti** |
| İki değişken arasında ilişki var mı? | Saçılım | `ax.scatter` | Korelasyon, kümeler |
| Bütünün parçaları? (az kategori) | Pasta | `ax.pie` | Oranlar (en fazla 5–6 dilim) |
| Çok değişkenli ilişkiler? | Isı haritası | `ax.imshow` + `df.corr()` | **Veri fazlalığı (redundancy)**, çoklu doğrusallık |

### Grafiklerden okunacak kritik dersler

**Histogram ve çarpıklık:** Sağa çarpık dağılımlarda (gelir gibi) **ortalama > medyan** olur, çünkü birkaç yüksek değer ortalamayı yukarı çeker. Bu tür değişkenlerde medyan daha güvenilir bir merkez ölçüsüdür; eksik değeri de ortalama yerine **medyanla** doldurmak daha uygundur.

**Kutu grafiğinin okunuşu:**

```
          o   ← aykırı değer (bıyık dışında kalan nokta)
          │
        ──┴──  ← üst bıyık: Q3 + 1,5 × IQR sınırına kadar olan en büyük değer
        ┌───┐
        │   │  ← Q3 (75. yüzdelik)
        ├───┤  ← medyan
        │   │  ← Q1 (25. yüzdelik)
        └───┘     kutu yüksekliği = IQR = Q3 − Q1
        ──┬──  ← alt bıyık
          o
```

**Isı haritası ve 2. hafta:** İki değişken arasında korelasyon çok yüksekse (ör. |r| > 0,9) biri muhtemelen diğerinin tekrarıdır (veri fazlalığı). Bu, **boyut indirgeme** için bir adaydır.

**Pasta grafiği uyarısı:** Kategori sayısı fazlaysa veya değerler birbirine yakınsa göz açıları karşılaştıramaz; **sütun grafiği daha iyi** bir seçimdir.

> 🦖 **Datasaurus'u hatırlayın:** Özet istatistikler aynı olsa bile veri tamamen farklı olabilir. `describe()` çıktısına bakmadan önce mutlaka bir histogram ve saçılım grafiği çizin.

## 11. Sık Yapılan Hatalar

| Hata | Belirti | Doğrusu |
|---|---|---|
| Listede `*` ile çarpmak | `[1, 2, 3, 1, 2, 3]` çıkar | Önce `np.array(...)` |
| Koşullarda parantez unutmak | `ValueError` / `TypeError` | `(a > 1) & (a < 5)` |
| `and` / `or` ile maskeleme | "truth value is ambiguous" hatası | `&` / `\|` |
| Dilimi kopya sanmak | Orijinal dizi "kendiliğinden" değişir | `.copy()` |
| `axis` yönünü karıştırmak | Beklenenden farklı sayıda sonuç | "Verilen eksen yok olur" |
| `== np.nan` ile eksik aramak | Hiçbir şey bulunmaz | `isnan()` / `isna()` |
| `std()` farkını bilmemek | Kitaptan farklı z-skor | NumPy: n, pandas ve kitap: n − 1 |
| `loc` ile `iloc` dilimini karıştırmak | Bir satır fazla/eksik | `loc` bitiş dahil, `iloc` değil |
| Türkçe harf dönüşümü | `"Istanbul"`, `"i̇stanbul"` | Dönüşümden sonra `unique()` kontrolü |
| `inner` join ile veri kaybı | Satır sayısı azalır, kimse fark etmez | Önce/sonra `shape` kontrolü |
| `savefig`'i `show`'dan sonra çağırmak | Boş resim | Önce `savefig`, sonra `show` |
| Etiketsiz grafik | Okuyucu ne gördüğünü anlamaz | Başlık + eksen etiketi + legend |

<summary><b>14. Bir öğrenci grafiği kaydettiğinde boş bir PNG dosyası elde ediyor. Kodunun sonu <code>plt.show()</code> ardından <code>plt.savefig("g.png")</code>. Sorun nedir?</b></summary>

`show()` çağrıldıktan sonra figür temizlenebilir; `savefig` boş bir tuvali kaydeder. Doğru sıra: önce `fig.savefig(...)`, sonra `plt.show()`.
